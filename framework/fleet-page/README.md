# loam-fleet-page (WS-A3)

One static HTML page answering *"what are my agents doing right now, are they alive, what
has it cost this week, and what needs a human decision"* — regenerated by a launchd/cron
job (never a `.claude/settings.json` hook), opened locally, no server.

It is a **view**, not a collector. It reads three existing sources through their public
API and renders four panels:

| Panel | Source | Public API |
| --- | --- | --- |
| Live agents (leads) | WS-A2 fleet collector | `loam.fleet_collector.collect_fleet()` |
| Recent outcomes | WS-A2 fleet collector | (finished runs from the same JSON) |
| Weekly cost (token proxy) | observability-aggregator | `QueryAPI.cost_by_prompt()` |
| Needs a human | per-project-pm | `load_decision_queue()` |

## Regenerate

```
python -m loam.fleet_page render --out ~/fleet.html --root <workspace-or-runs-dir>
```

The command re-reads every source and overwrites the page. Any source that is unavailable
(uninstalled, store missing, read raised) is labeled *"source unavailable"* on the page —
the remaining panels still render, and nothing is invented. An **empty** source (no live
runs, no queued decisions, no recorded cost) renders its own explicit empty state, which
is distinct from a missing one.

## Schedule it (launchd, darwin)

```
python -m loam.fleet_page install-launchd --out ~/fleet.html --root <dir> --interval 300
```

Writes a launchd plist to `~/Library/LaunchAgents/` whose `ProgramArguments` invoke the
`render` command above on a `StartInterval`. Load it with
`launchctl load ~/Library/LaunchAgents/com.loam.fleet-page.plist`. The plist references
only this module — never `.claude/settings.json` (Track F is the sole settings.json
writer this phase).

## Design notes

- The cost strip reports **token counts**, labeled a proxy — never dollars (isolated
  subscription agents meter no per-call dollar figure; a `$0` would be invented data).
- The live table's cost column shows the fleet collector's honest `cost_usd` when present,
  else its `cost_source` string (e.g. `absent`) — never a fabricated `$0.00`.
- Dark/light via `prefers-color-scheme`; wide cells wrap (`overflow-wrap: anywhere`) and
  tables scroll inside their own container, so a long run path or objective never forces
  horizontal body overflow.
